## Infrastructure & Platform

My self-hosted Forgejo instance runs on infrastructure that I operate myself.

The homelab is also an ongoing technical project spanning virtualization,
storage, networking, containerized services and development infrastructure.

```text
                         Internet
                            |
                      Cloudflare
                            |
                         Tunnel
                            |
                         Caddy
                            |
                        Forgejo
                       /       \
                  PostgreSQL    CI
                              Runners
                                 |
        +------------------------+------------------------+
        |                        |                        |
    Proxmox                  TrueNAS                 Linux
  virtualization             storage               services
        |                        |                        |
       VMs                    ZFS data               Infisical
      LXCs                    backups            secrets management
```

The environment currently includes:

- multi-host Proxmox virtualization
- TrueNAS and ZFS-backed storage
- Linux virtual machines and containers
- Docker workloads
- self-hosted Forgejo repositories
- CI runners and automated workflows
- Cloudflare Tunnel for public services
- Caddy reverse proxying
- internal DNS and service discovery
- centralized secrets management with Infisical
- monitoring and backup workflows

`Proxmox` `TrueNAS` `ZFS` `Linux` `Docker` `Forgejo` `Infisical` `CI/CD` `Cloudflare` `Caddy`

> Hosting the repositories is only one part of the project — maintaining the
> platform behind them is part of the development workflow too.
